# Pesquisa de Opinião - TudoWeb

Este projeto foi desenvolvido como atividade da Agenda, utilizando a linguagem Python.

A proposta é simular uma pesquisa de satisfação feita pela empresa TudoWeb com seus clientes. O programa solicita o nome, a idade e a opinião de cada entrevistado sobre o atendimento recebido.

As opções disponíveis são:

- 1 - EXCELENTE
- 2 - BOM
- 3 - RUIM

Ao final da pesquisa, o programa mostra a quantidade de respostas **EXCELENTE** e **RUIM**.

## Arquivos do projeto

`pesquisa_opiniao.py` - versão principal da atividade, preparada para 50 entrevistados.

`teste_10_entrevistados.py` - versão utilizada para realizar os testes solicitados com 10 entrevistados.

## Conceitos utilizados

Durante o desenvolvimento foram utilizadas estruturas de repetição com `for` e estruturas de decisão com `if`, `elif` e `else`.

## Testes

Para validar o funcionamento do programa, foi realizada uma versão de teste com 10 entrevistados, conforme solicitado na atividade.
